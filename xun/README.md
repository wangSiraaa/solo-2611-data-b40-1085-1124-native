# xun — 陶埙试音台：精确音窗、谱单可行性与尾声交付规划

纯 Python 3.11 + 标准库（`fractions.Fraction`）。与主仓库 `obsdelivery`
同一工程约定：不引入宿主浮点，二进制孔位、线性插值、容差判定、气压方向
与短十进制显示全部在精确有理数上完成。

```
xun/
  model.py         孔位/试吹线数据模型 + 相邻实测点精确线性插值（不跨缺测档）
  windows.py       奏准音窗：闭压力区间 + 边界支撑证据（实测/插值/压线）
  phrase.py        谱单逐拍可行性：方向选线、连音限动一指、换气休止重置
  coda.py          指挥尾声规划：有号双面牌暗号 / 整拍静默的最小代价因果策略
  delivery_note.py 读谱台短十进制展示（只展示，绝不参与合格判定）
  demo.py          本地复跑（音窗、两孔短句、自定义补句、尾声分叉）
tests/test_xun_*.py 精确断言 + 对音窗/谱单的独立暴力交叉核对
```

运行：

```
python3 -m xun.demo
python3 -m pytest -q
```

## 1. 试音台与精确插值

孔位是二进制串（左→右对应高→低位）。每套开孔在若干档气压下各有两条
试吹线：`attack`（吹响，气压上升/持平）与 `release`（收气，气压下降）。
每档读数是精确 `Fraction` 或缺测 `None`。

* 只有**相邻实测点**之间作精确线性插值；中间隔着缺测档则不连，绝不跨缺测；
* 奏准条件 `|pitch(p) − target| ≤ tolerance`，闭区间，恰好压线算合格；
* 每个区间端点保留证据：位置（实测档 `data` / 插值段内 `interior`）、
  所属试吹线、所在插值段，以及 `on_tolerance`（是否贴 target±tolerance）。

## 2. 谱单逐拍可行性

每拍给音名、可选气压（`None` 自选）与可动指位 `movable_mask`：

* 气压上升或持平 → 吹响线；下降 → 收气线；首拍方向随谱，休止后视同首拍；
* 连音（相邻奏拍无休止）至多动一指，且变动孔须落在 `movable_mask` 内；
* 换气休止不发音、放手，后续奏拍重置；
* 回溯在全部（指位 × 试吹线 × 候选气压）上进行，失败报最深的阻断拍。
  候选气压取各音窗端点与上一拍压力（覆盖“持平走吹响”的内部点）。

## 3. 短十进制不洗白

`delivery_note` 用精确偶舍入给出短十进制系数，仅用于读谱台显示。合格判定
只认真实 `Fraction` 与容差；当显示值落在容差内而精确音高在窗外时，
`display_probe(...)["whitewashed"]` 为真，结论仍是不合格。

## 4. 尾声交付规划（指挥视角）

指挥开演前拿到尾声版本，乐手只在谱牌揭示点 `reveal_gap` 后看见自己的
谱牌。规划器按**知识分区**做因果校验：同一知识单元内的多个尾声在该拍
必须采取完全相同的（指位, 试吹线, 气压）动作。

* **有号双面牌**：在授权空拍 `signal_gaps` 给一位乐手一个二值暗号，把
  分区细化；一张牌同场只能借给一队（`CardLibrary` 登记，转借抛错）；
* **整拍静默**：在观众约定的间奏位 `silence_gaps` 静默一次，真实静默才
  允许放手重置；必须把结束窗让出一拍（`window_extension_required`）；
* `plan_minimum` 分别给出最少暗号与最少静默两条路线，并由 `describe_cost`
  说明代价落在哪位乐手或哪个首末拍；
* 某尾声在物理上无可行路径时抛 `InfeasibleCoda`——给牌、挪拍都救不了。

## 5. 本地复跑覆盖的题面情形

* 两孔单档定压：`00→01` 可演；仅重测 `01` 成 `3/2` 后，`11` 虽准却因
  可动指位限制接不过去；恢复试吹、只锁次拍右指仍接不上；
* 三孔五拍补句：中间档插值得音、下降收气线另有音高、换气后重置；
* 尾声分叉：首拍 `00/11` 同音、下一奏拍锁指、甲尾只准 `00`、乙尾只准
  `11`；早牌（1 位暗号）与“揭谱后静默 + 让窗”两条最小代价路线，以及
  撤掉 `11` 实测音窗后乙尾的物理不可交。
