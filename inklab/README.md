# inklab — 蘸水笔供墨模型、率求解与开笔安排

`inklab` 建在仓库既有的 `obsdelivery`（精确 binary32 观测库 + 规范产品）之上，
把「笔尖 / 储墨腹两室、逐拍供墨、称量读数、供墨率反解、开笔换笔」实现为精确有理数。
不经过宿主浮点。

运行：

```
python3 -m inklab.demo          # 人读：全部实算场景
python3 -m inklab.demo --json   # 结构化输出
python3 -m pytest -q tests/test_inklab.py
```

## 供墨规约（`model.py`）

笔有尖、腹两室。每拍：

1. 尖先支付该笔画所需墨量；尖不足以支付则**断线**，本拍不画。
2. 腹再补尖，上限为三者的最小值：

   ```
   补给 = min(该方向供墨率, 腹内余墨, 尖容量 - 尖上余墨)
   ```

供墨率按 `(笔, 方向)` 固定整场。方向为 `h`（横）/`v`（竖），宽窄笔耗折进 `cost`。

## 仪器分辨率（`instrument.py`）

秤只报「当时真实可辨的刻度」——`Instrument` 把精确读数映射到桶键：

* `exact_instrument()`：每个精确值自成一桶；
* `group_instrument([[0,1]])`：把 0、1 并为同一读数档；
* `contract_instrument(contract)`：桶 = 读者合同能交付的十进制。

**同键即不可分辨**：登记为同一读数的两种供墨率不得偷分。

## 率求解（`solver.py`）

给定试验（笔容量、逐拍方向与耗墨、起始两室、按腔室与仪器桶记录的观测），
穷举少量候选率组合，只保留其模拟读数在**仪器桶**上与全部观测一致的组合。
无存活者 → `SolveResult.conflict=True`（空集报冲突）。`SolveResult.explanations`
可只查某支笔为何仍有两条率。

## 供墨表核验（`ledger.py`）

`InkLedger` 把称量读数经 `bits.encode_bits` 编成真实 binary32 位型登记入旧观测库；
再以候选供墨表作为参考期望发布规范产品，读回每条 `abs_difference`：
**全部为零**才算该表解释全部逐室称量。报告 / 产品不可变、可重开
（`build_report` / `reopen_report`）。这正是简报所说
「用旧观测库登记真实位型，以规范产品的精确差量核一份可重开的供墨表」。

## 开笔与换笔安排（`planner.py`）

`World` 是一种可能的率配置；`evaluate` 在每个世界执行同一份计划：

* `Test`：驻场试划一笔并按真实规约耗墨，再称尖；
* `DryTest`：检验台干测夹位，只比对具名参照尖，不耗墨；夹位撤除后 `compare` 返回 `None`；
* `Dip`：蘸至台卡指定两室量（不把别处耗掉的墨还回）；
* `Body`：选笔器**只看已记录的观测桶**（看不到真实率），且整段一笔画完（连续笔画不换笔）。

`PlanReport.guaranteed` = 每个世界都画完；`max_test_ink` = 各世界试划耗墨的最大值
（即「以各可能率中的最多试划耗墨计」）。`best_guaranteed` 取保证写完者中试划耗墨最少者；
`worth_discriminating` 判断何时值得花墨去辨别。`indistinguishable_worlds`
给出观测完全相同、因而无法偷分的世界组。

## 本地称量原件（`trialgen.py`）

`generate_originals` 在「最多五笔十拍」的界内，把一次小型试验逐腔室读数
本地编成 binary32 原件，超出界或读数不可精确表示则 `ValueError`。

## 已签交接（`handoff.py`）

`sign_handoff` 对观测、所选笔、承接两室状态、已耗试划墨、接手人做内容摘要。
`continue_from` 只在承接墨量不超过已签记录、未回滚已耗试划墨、所选笔一致、
摘要自校验通过时放行——即「接手保留实际落笔的线，不还原以前的墨」。

## 简报场景对照（`scenarios.py`，全部实算并由 `tests/test_inklab.py` 钉住）

| 场景 | 事实 |
|---|---|
| S1 尖腹2/2 满笔 横耗2 补给后称得尖1腹1 | 唯一率 = 1 |
| S2 满笔 先横2 后竖1 | 能写完（率1/1） |
| S3 试笔末值更正为尖0腹2 | 率为0；横后无墨，竖画断（活页拒收） |
| S4 原表仅末拍改宽竖耗2 | 竖画断，同样拒收 |
| S5 尖1腹2 先横1再称尖（率0/1） | 分别读 0 / 1 |
| S6 三连划（A/B 装箱，尖1腹1 腹3） | 无证据无法保证；驻场试划或干测均可保证；干测零耗墨更优 |
| S6 四连划 不补墨（快笔恰4单位） | 驻场试划**无法保交**（吃掉快笔1单位）；干测可保证；撤掉唯一夹位即失败 |
| S6 把 0/1 并为同一档 | 试划不再可分辨，两世界无法偷分 |
| S7 两套率 | 一条字线两率皆通，另一条不能保证 |
| ledger | 正确表全差分为0；错误表最大差1；报告可重开同摘要 |
| nonunique / conflict | 同一笔两条率（平台）；观测无解则冲突 |
| originals | ≤5笔10拍，本地生成原件，超界拒收 |
| handoff | 同状态可续；还原墨/回滚试划墨被拒 |
