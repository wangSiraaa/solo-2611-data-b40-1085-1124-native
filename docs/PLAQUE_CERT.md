# 巡演协会销量认证与两馆刻牌模型

只依赖 Python 3.11 标准库。回答的核心问题：**套装里两张唱片都卖出了，
认证处能否同时发两张销量牌？** —— 能不能发、最多几张，取决于门槛、联号
条款与退货状态，由 `alloc.max_plaques` 回溯求解；演示证明“原可两张都发”
的同一组交易，整包退一只后最多一张，加同牌联号条款后也最多一张。

## 1. 目录结构

| 路径 | 职责 |
| --- | --- |
| `plaque_cert/reconcile.py` | 销售核单、异常报告、带哈希链的合格包册 |
| `plaque_cert/alloc.py` | 门槛 + 发行名/再版归并 + 联号全有全无约束下求最多牌 |
| `plaque_cert/halls.py` | 两间刻牌室：联网签印台 / 离线具名模具两种作业模式 |
| `scripts/run_plaque_demo.py` | 题面全部试办场景的端到端演示（含断言） |
| `tests/test_plaque_cert.py` | 21 个单元测试 |
| `state/plaque_cert/*.json` | 可复查产物：包册、异常、两馆事件日志 |

运行：

```bash
python3 -m scripts.run_plaque_demo
python3 -m unittest tests.test_plaque_cert -v
```

## 2. 销售核单与合格包册（reconcile.py）

题面规则到实现的映射：

| 题面规则 | 实现 |
| --- | --- |
| 外部收银凭据列具名包号、货号、客单、成交行 | `ExternalReceipt`；成交行货号必须落在包原配内 |
| 内部一箱交接不能报零售 | `InternalTransfer` 镜像只登记；无外部凭据的包判 `revoked`，异常写明“内售发票齐但实际外售缺席” |
| 一包只可由收货卖场凭真实成交计一次 | 凭据卖场须等于 `Package.store`；同包第二张凭据进异常 |
| 整包退 / 只退指定盘，退量符合原配 | `ReturnVoucher`；逐盘累计退量 > 原配即异常，合规部分照退 |
| 旧底稿只记未对外售出数 | `PeriodDraft.unsold_external`；批次总盘数 − 未售数 = 底稿隐含售出 |
| 补办退回实物另册验收 | `reprocessed=True` 进 `reprocessed_book` |
| 逐批以原售出数 − 实退数核合格份数，对不上的包报告 | `run()` 批次对账，不符进 `issues` |
| 可复查的合格包册，写明每个码仍可为哪些唱片作证 | `BookletEntry.eligible_releases`；逐条 SHA-256 哈希链，`verify_chain` 独立复查，篡改即断链 |
| 限十二包 | `MAX_PACKAGES=12`，第 13 包登记即抛错；牌上限 `MAX_PLAQUES=5` |

部分退货时包册按**留存盘**给证：双盘包只退乙盘，该码仍可给甲盘作证。

## 3. 最多可发牌（alloc.py）

- 一个有效码至多盖一张牌（`used` 集合保证不重复）；
- `PlaqueSpec.accepted_releases` 表达各牌可接受的发行名；再版是独立
  `Disc`，只有显式纳入归并许可才能计入（演示中撤销许可后 5 张降为 4 张）；
- 联号组以“原子”参与回溯：整组同盖一张牌或全不盖，`_check_group_integrity`
  与求解器共同保证不可拆；
- DFS 带“剩余牌数上界”剪枝，平局按字典序稳定出单（同数任选）。

## 4. 两馆刻牌室（halls.py）

**采用模式：离线具名模具（`OFFLINE_MOLD`）**。馆与馆离线，联号模具由一馆
独占（`mold_holder`），码组换手只在已登记交班点 `HP-1` 发生，模具随组交接。
联网签印台（`ONLINE_SEAL`）作为等价事件对照一并实现：授权前只能预排，
授权基于签印台已受理退盘与落印回执。

码的四种状态与出库名单分类：

| 状态 | 含义 | 出库分类 |
| --- | --- | --- |
| `unengraved` | 未刻仍有效（含在途、仅预排） | 可用 / 在途 / 仅预排 |
| `revoked` | 未刻即遇退盘，资格撤销 | **已撤销资格**（码没被刻过） |
| `engraved` | 已永久刻入牌铭边 | **真的永远不能再刻** |
| `withdrawn` | 已刻后退货，牌撤证 | **真的永远不能再刻（已落印，牌已撤证），码不发还** |

关键时序规则：

1. `schedule` 只预排；`authorize` 要求实物在承办馆（在途拒授）且码有效；
   联网模式还要签印台未受理该码退盘。
2. 退单先到非持馆只记 `return_notice`，**不暂停任何新刻**；
   持馆办理时刻起，对退盘涉及码暂停其后新刻（`paused_codes`，不波及其它独立码）。
3. 落印是永久的：已刻码退货只能 `withdrawn` 撤证，任何重新接单都报错。
4. 换班 `shift_change` 旧刻单存档，新申请重新授权。
5. `dissolve_group` 解除联号后，仍有效码成为独立码，可单独换馆、单独成牌。

### 试办结论（西馆 → 东馆，联号两码在途，异馆收到退单）

- **东馆只有全量拟成交包册**：在途时授权被拒（实物未到），接单不能转刻印；
  交班完成、模具随组到东（离线）或最终授权下达（联网）后，退单仍只在
  异馆、持馆未知，已到点的合法承诺在**东馆实刻**；持馆其后办理退盘，
  牌记撤证，两码永久不还。
- **东馆已接收真实模具 / 最终授权，持馆落印前办理退盘**：暂停其后新刻，
  两码未刻，均为 `revoked`（已撤销资格），出库名单与 engraved/withdrawn
  的“永远不能再刻”明确区分。

## 5. 演示场景索引（run_plaque_demo.py）

1. 场景一：两专码 + 两只双盘包，整包退一只 → 最多 **1** 张；
2. 场景二：恢复四码，无联号可发 **2** 张；仅套装码加同牌联号 → 最多 **1** 张；
3. 场景三：十二包五牌上限拦截、再版归并许可开关（5 → 4 张）、
   内售有票外售缺席拒绝、旧底稿对不上进异常；
4. 两馆试办：两种模式 × 两种到点状态的时序对照；
5. 联号解除：已刻退盘只撤证不还码，独立码单独换馆再刻。
