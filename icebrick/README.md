# 三色冰砖模拟（备料台 + 单窗/两窗出摊规划）

纯 Python 3.11 标准库，无第三方依赖。层厚度均为至少 1 的整数；题面规模约束
（完整可行读法 ≤ 6 种、至多三砖四杯、每砖 ≤ 6 格）在代码里显式检查，超出即报错。

## 一键复跑

```bash
python3 -m tests.test_icebrick     # 27 项断言
python3 -m icebrick.demo           # 题面全部杯单的可读演示
./run_tests.sh                     # 连同预算解算系统一起复跑
```

## 模块

| 文件 | 职责 |
| --- | --- |
| `icebrick/model.py` | 砖/层/量条（相邻层和 `SumSlip`、同模厚差 `DiffSlip`）、冻结快照 `FrozenModel`、整数区间传播、读法枚举（上限 6）、矛盾凭据、备料查询（可能口味/两处同见） |
| `icebrick/window.py` | 实物状态（剩余区间不可逆）、杯/轮班表、单窗信念规划 `plan_single_window`、两窗分布规划 `plan_distributed`（仅试切办法）、联络挪后核验 |
| `icebrick/simulator.py` | 独立于搜索器的物理模拟器：逐拍复算端/格位/落杯/废料/截止班/窗口归属/不回退 |
| `icebrick/demo.py` | 题面全部示例的实杯单 |
| `tests/test_icebrick.py` | 单元断言 |

## 关键语义与设计决策

### 1. 量条与格号进同一冻结快照

`IceModel.add_brick/add_sum_slip/add_diff_slip` 在建模阶段完成全部引用核对
（砖存在、层号不越界、厚差量条要求两砖 `mold_id` 相同）。`freeze()` 计算内容
哈希并产出不可变 `FrozenModel`；规划侧只面对快照，量条引用的格号随之固定，
与预算系统“目录—快照—不可变产物”的复现理念一致。

### 2. 读法枚举与矛盾凭据

* 每块砖自带“层厚和 = 总格数”的全幅和约束，与量条一起做区间传播（和约束的
  min/max 收紧、单变量定值；厚差双向收界），再回溯枚举完整整数读法。
* 枚举到第 7 种读法抛 `TooManyReadingsError`，不静默截断。
* 无解时 `contradiction_witness()` 贪心删条求局部最小不可满足量条子集，并给出
  传播后的空界/违例量条说明（`InfeasibleModelError.witness`）。

### 3. 单窗规划（保留的单窗入口）

`plan_single_window` 在信念（与已观察事实相容的读法集合）上做 AND-OR 搜索：
切的决定是 OR（选砖/选端），见色分支是 AND（每种可能颜色都必须有合法后继）。
当拍必须落进“下一层正好要该颜色”的杯或用一格废料，不许暂存；杯过截止班即失败。
失败时 `failure_branch` 沿任一具体读法给出首个失约点的观察分支凭据。

记忆化键只含物理状态（节拍、各砖剩余区间、各杯剩余层、废料额）：已切格位与
见色历史已完整投影到物理状态，信念由物理状态重新推导；失败节点不缓存，避免
“同一物理局面在不同决策路径上成败不同”被污染。

### 4. 两窗分布规划：只实现冷柜试切一种出摊办法

题面允许在“临场联络拍”和“开卖前冷柜试切”中二选一实现，本仓库**只实现试切**：

* 试切候选 = 带同模签、当前仍可从给定端取格的砖；试切片必须由一格废料额接住，
  不能进当班杯（无废料额直接 `CupOrderError`）；
* 试切把真实读法按实见颜色分组，颜色印上两窗备料卡，各组独立求解演出策略；
* 演出实物状态中试切格已消失，不能还原、也不会要求该窗再切一次重取证据；
* 窗口只看得见自己的砖/杯，`commitments` 以
  `(节拍, 窗口, 该窗砖区间, 该窗杯剩余)` 为键强制：**同一窗在两种自己无法区分
  的经历里必须作同一个决定**；对窗杯不可落（模拟器独立复算）。

`use_test_cut=False` 走“不领冷柜时段”的信念搜索，题面三砖示例由此证明无保证；
`comm_after_analysis` 显式核验“联络机会从乙下刀前挪到切完后”乙无法保证杯底红：
乙两砖左端在两种读法下都可能是蓝或红，各附反例读法。联络拍消息机制本身不实现。

## 题面杯单索引（`icebrick/demo.py`）

| 场景 | 配置 | 结论 |
| --- | --- | --- |
| 1 | 一砖红蓝共 3 格、红=1，只左切无废料；杯甲自底红蓝、杯乙要蓝 | 三拍可交（R→甲, B→甲, B→乙） |
| 2 | 量条改红=2，杯单不变 | 无保证：蓝只有一片，必少一蓝 |
| 3 | 红=1，甲单改蓝红、两杯都蓝开头，只左切 | 无保证：第一片红无处放 |
| 4 | 三砖两窗（t∈{1,2}，各预切首格红），甲再左切、乙两砖任选左切交杯底红 | 试切甲砖下一格：见蓝则乙切 Z、见红则乙切 Y；不试切/联络挪后均无保证 |
| 5 | 两砖同模 t∈{1,2}，P 只左切、Q 只右切，四杯无废料 | 固定切序、按见色分流到红/蓝杯，两种读法都准点 |
| 5b | 单砖 t∈{1,2} 两端皆可，急蓝杯拍 0 要蓝 | 规划器自选先右切（左切首格恒红必失约） |
| 附 B | 红 2 + 蓝 2 但砖长 3 | 矛盾凭据定位到两条量条子集 |

### 场景 4 实杯单（选用的试切办法）

* 备料（冷柜时段，额外）：甲砖 X 已依法预切首格红后，再从左端试取一格
  （原格号 1）。t=1 实见蓝、t=2 实见红；该格计 1 格废料、不进杯、演出不还原。
* 演出轮班：拍 0 甲动、拍 1 乙动。
  * 甲：X 再左切一格，恒为蓝，落 `甲蓝杯`（deadline 1）。
  * 乙：备料卡为蓝（t=1）→ 切 Z 左端得红；备料卡为红（t=2）→ 切 Y 左端得红；
    落 `乙红杯`（deadline 1）。
* 两窗在全部两种可行读法下均准点交齐，由 `simulator` 逐读法独立复算。
