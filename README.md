case.json分录每行是[account,debit,credit]，金额为整数分，0代表该侧无金额；一行必须恰一侧大于0。document为null表示普通外部/期初凭证。seller_i1/buyer_i1文档镜像同i1；remaining_stock i1=2是买方尚未售出的件数。external_sale是买方对外售出两件的普通凭证；settlements独立发生，不改变剩余实物数量。材料不含账簿或合并服务代码。

红利/股东册子系统（新增，与集团合并底稿并列）
===================================================

运行：

```bash
python3.11 scripts/run_dividend.py                 # 九组场景端到端演示
python3.11 -m unittest tests.test_dividend -v      # 红利子系统单元测试
```

模块（`group_consol/`）：

| 模块 | 职责 |
| --- | --- |
| `book.py` | 可追溯账簿 + 可分余额：对外收入−对外成本 + 内部已实现毛利 − 另册有效亏损 − 已宣告未撤销；最低取零；旧版凭证/冲回被 `supersedes` 后不计入 |
| `allocation.py` | 股东册分派：普通余款、优先整类转普通/按序取定额、短缺后类承受、稳定选择筛选、保底承诺 |
| `custody.py` | 红利权（claim）拆分锁定、实体息票拆转、登记处柜面、巡回付款台 |
| `dividend.py` | 端到端门面：入账→算余额→稳定筛选→宣告→开 claim→兑领 |

要点对应题面：

- **可分余额**：P 内售 S 4 件（T=16,C=8），S 对外卖 2 件收入 10，另一笔对外净利 6；
  内部毛利留库 `(T−C)×r/q=(16−8)×2/4=4` 不进可分，仅已实现部分进当期收入 ⇒ 可分 12。
- **宣告锁余额**：宣告记录（`bk_declarations`，Fraction 原样）一旦入册即从后续可分中扣除；
  后加单体账只改变新批次，旧宣告永久不变（`scripts/run_dividend.py` 场景 I）。
- **亏损冲回**：原亏损可被正式冲回一部分，冲回累计 ≤ 原额；旧版冲回被替换后再用 ⇒ `stale_reversal`。
- **稳定选择**：每个可转类单独反转若不能增加自己所得则该选择稳定；只在稳定方案上取每人区间，
  区间仅用于判断保底承诺（承诺 ≤ 每个稳定选择下所得）。无稳定选择时输出每个被否选择的一次获益偏离。
- **兑领归属**：拆转立即从原 claim 扣减；两张相冲申请先到锁定、后到因余额不足被拒；
  已实付份额不能再转。甲宣告 4，卖股给乙并另转 1 元息权给丙 ⇒ 乙不能领，甲/丙各领 3/1。
- **两条兑领通道**（余额相同、两次到柜）：
  - 登记处柜面（每日一班）：转入 claim 的转让回执**入册前**拒付并指明去哪核、等到哪步；入册后签付。
  - 巡回付款台（可同日到分馆）：必须先交**真实、未拆、未领**的实体息票；拆票必须收旧票再交只带
    「拆前旧票号码」的子票；领过的真票被收走不得退还；只凭票面真伪与本地票号簿核验，不联查登记处。
